WNBA Game Outcome Prediction

Logistic regression on merged schedule and advanced-stats data, with predictors chosen by sequential feature selection. 70.4% accuracy.

Context

Aggie Analytics, UC Davis, Oct 2023

Tools

Python, pandas, scikit-learn

Code

Repository not yet public

The question

Can a simple, explainable model predict who wins a WNBA game from team statistics? I wanted a model I could explain line by line, so I chose logistic regression over a black box.

Approach

  1. Clean and merge. Imported season schedule data and advanced team statistics, cleaned both, joined them, and added a column marking whether the home team won.
  2. Pick predictors. Used a sequential feature selector to narrow the statistics down to the 10 most useful predictors.
  3. Train and test. Fit a logistic regression model and evaluated it with Monte Carlo simulation over repeated train/test splits.
  4. Apply it. Used the model to predict a finals matchup between the Las Vegas Aces and New York Liberty.
Result70.4%

accuracy predicting game winners.
