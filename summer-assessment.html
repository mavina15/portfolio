Operations case study · 2026

Summer Assessment Program

Scheduled and ran testing for 147 students across four home languages, then wrote the placement report used to set next year's cohorts.

Context

Making Waves Academy, Summer 2026

Tools

Google Sheets, email, phone outreach

Code

Internal school data, not public

The problem

Every incoming student needed a placement test before the 2026–27 school year. The tests had to be scheduled with families, run on fixed dates, and staffed with help from IT, operations and food services. Leadership needed the results in time to set next year's class groupings.

Bars are drawn to the same scale (147). Completion is 125 of the 146 students expected to test. The remaining families were followed up with by phone and email.

Almost half of families got notices in a language other than English. Students with IEPs and 504 plans got tailored versions.

What I did

  1. Built the roster. One sheet tracked every family: testing week, preferred language, confirmed date, whether the confirmation email went out, and notes.
  2. Confirmed dates. Reached 131 families directly, then followed up with the rest by phone and email.
  3. Coordinated the teams. Worked with leadership, IT, operations and food services so rooms, devices and meals were ready on each fixed test date.
  4. Reported the results. Wrote a summary report with placement results and recommended student groupings. Leadership used it to finalize the 2026–27 cohorts.
Outcome86%

completion, 125 of 146 students tested on a fixed schedule, with results delivered in time to set next year's cohorts.
